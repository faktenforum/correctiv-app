# Review images

Screenshots referenced from pull request descriptions, so a reviewer can see what a
change looks like without checking it out and starting two servers.

**This branch is never merged.** It carries no code and shares no history with `main`;
it exists because GitHub renders an image in a description only from a URL, and the
repository is not the place for screenshots taken to argue one review. The curated set
that *is* part of the repository is [`screens/`](../../tree/main/screens), which is a
fixed tour shot on a device and compared frame by frame. These are not that.

Taken with headless Chrome over CDP against the branch each one names.
